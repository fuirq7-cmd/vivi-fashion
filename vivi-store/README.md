# VIVI FASHION — المتجر + السيرفر + قاعدة البيانات

سيرفر Node.js كامل وقاعدة بيانات SQLite، بدون تثبيت أي مكتبات. يتطلب Node.js 22.5 أو أحدث.

## التشغيل على جهازك
    node server.js
ثم افتحي http://localhost:3000

## النشر على الإنترنت (مثال: Render أو Railway)
1. ارفعي هذا المجلد إلى مستودع GitHub.
2. أنشئي Web Service جديداً واربطيه بالمستودع.
3. Runtime: Node (نسخة 22 أو أحدث) — أمر التشغيل: `node server.js`
4. أضيفي Disk/Volume دائماً (مثلاً مسار `/data`) حتى لا تضيع البيانات عند إعادة التشغيل.
5. أضيفي متغيرات البيئة:
   - `DATA_DIR` = `/data`  (مسار الـ Disk)
   - `ADMIN_PASSWORD` = كلمة مرور قوية للمدير (تُستخدم عند أول تشغيل فقط)
   - `ADMIN_EMAIL` = fu.irq7@gmail.com (اختياري)
6. افتحي الرابط الذي يعطيك إياه الموقع (يعمل بـ HTTPS تلقائياً).

## ما الذي يحفظه السيرفر
المستخدمون (كلمات المرور مشفّرة بـ scrypt)، المنتجات وصورها، الطلبات، أسعار التوصيل (بغداد/المحافظات) ورقم الواتساب.
الأسعار والمجاميع وأجور التوصيل تُحسب في السيرفر ولا يمكن التلاعب بها من المتصفح، ويُخصم المخزون تلقائياً.
